# CodeWordOmega Portfolio

A modern, visually impressive portfolio website for a Full Stack Developer with Web3 and Solana blockchain experience. Built with React + Vite and inspired by [blaysloyality.com](https://www.blaysloyality.com).

---

## 🚀 Features
- Bold, dApp-inspired hero section
- Project showcases with images and detailed descriptions
- Skills, achievements, education, and contact sections
- Clean, professional, and responsive UI
- Ready for deployment on GitHub Pages

## 📦 Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Start the development server:**
   ```sh
   npm run dev
   ```
3. **Build for production:**
   ```sh
   npm run build
   ```
4. **Preview the production build:**
   ```sh
   npm run preview
   ```

---

## 🛠️ Tech Stack
- React + TypeScript
- Vite
- CSS Modules / Tailwind CSS (customize as needed)
